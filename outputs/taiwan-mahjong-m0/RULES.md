# TW16-CLASSIC-v1 固定桌規

版本：M0.1｜2026-10-04｜狀態：本案實作基準，非全台統一標準。R 為流程規則、S 為台項；修改語義須升版本，不重用 ID。本文取代規劃稿未定細節；標為「本案補充」者是明確選定的邊界處理。

## 牌局與操作

**R01 牌組與牌數。** 144 個唯一實體牌：萬筒索 1–9、東南西北中發白各四張，春夏秋冬、梅蘭菊竹各一張。花另列；有效牌數 E＝暗手張數＋3×面子數，槓也算一面子。通常待進牌 E16、待出牌 E17；補牌中可不足。花胡依 R13 豁免。任何實體牌只在一處；被取走的捨牌只留歷史引用。

**R02 座位。** 座位 0–3 按逆時針固定，下一家為 (s+1)%4。首莊隨機；門風由莊位起東南西北。公平洗牌；四輪每家各取四張，再給莊家一張。首輪從莊家開始，依同一逆時針座序發牌。

**R03 牌牆。** 設未取區間 [head,tail]；可用數 A＝max(0,tail−head+1−16)。普通進牌取 head 並加一，補牌取 tail 並減一；每取一張 A 減一。保留的是未取張數，不是預先指定的 16 個牌 ID；槓不另增加保留數。A=0 禁止任何抽牌與新開槓。本案補充：補牌與正常摸牌共用此邊界。

**R04 起手補花。** 發牌後全部起手花公開。莊起逆時針，每家在一輪只補輪到自己時已有的欠牌數；本輪補入的新花公開、欠額留到下一輪。反覆直到莊 E17、閒家 E16；全部完成才判開局花胡，再判天胡。行牌時摸花立即公開，連續從尾補至一般牌或 A0。補花不破壞第一巡。

**R05 階段。** 發牌／起手補花完成，先依 R04 檢查開局花胡；未結束則莊家 E17 直接進自家選擇（天胡／合法暗槓／出牌），首打前不得再摸。莊家首打後才循環：捨牌回應 → 下家待摸 → 行牌補花 → 自家選擇 → 捨牌回應。吃碰返回自家出牌，槓經補牌返回自家選擇，加槓先進搶槓回應。終止後為結算展示 → 下一局或一將結束。每步先提交狀態再播放動畫；自動階段一次只完成一個抽牌事件。保存階段、欠補、回應及局面序號；恢復不得重摸。拒絕錯玩家、錯階段、過期及重複操作。

**R06 一般胡牌。** 五個順／刻／槓加一對將；順子只能同門數牌連續三張。允許零台；無八對半、七對、十三么、役門檻或日麻振聽。W(H,M) 為 E16 局面加入一種一般牌後能成立的全部牌種，排除玩家已持有四張的牌種；只看牌型，不看過水、進牌來源及公開剩餘量。

**R07 回應仲裁。** 捨牌後先胡、再碰／明槓、最後下家吃。多家胡採距出牌者逆時針最近者；不得用回應抵達時間決定。收齊尚可能改變裁決的回應才提交；低順位被擋不算放棄胡或碰。真人不限時；AI 也只能提交合法動作。最後捨牌及搶槓同樣等待完成。

**R08 吃碰。** 吃限上家；碰可任一家。吃後禁打能和所用兩張暗手組成順子的所有牌種（34 吃 2，禁 2、5）；碰後禁打碰牌同種。若因此沒有可捨牌，該吃碰不合法。吃碰後不能立即槓或自摸，必須先捨牌。

**R09 回吃碰與過碰。** 記錄自己的最後捨牌種，在自己打出不同牌以前不得吃碰回該種。放棄合法碰則記錄該種過碰，直到自己下一次捨牌後清除；摸牌、補花不清除。本案補充：過碰是牌種集合，僅限制碰；明槓另依 R10，不能以碰冒充槓。

**R10 三種槓。** 明槓用暗手三張加他家捨牌，禁止取上家；暗槓用自有四張，對其他人隱藏牌種；加槓用已碰面子加暗手第四張。暗／加槓限自己的摸補後選擇階段。加槓先保留原碰，第四張仍屬原玩家暗手、被暫鎖，pending 僅存引用，再詢問搶槓；有人胡則第四張移至結算區、不成槓、不補牌；無人胡才移入槓並解過水。明槓後本次出牌前禁止一般自摸，包括連續補花及再次暗／加槓補牌（後者為本案補充，避免繞過禁制）；其他回合的暗槓／加槓／正常摸花補牌可一般自摸。吃碰不開槓；四槓不另流局。

**R11 過水。** 自願放棄「當下合法」一般胡、自摸或搶槓即設過水，禁止全部聽口的一般胡、自摸及搶槓；被攔胡不設。對欲捨的 t，先以捨後 H′ 計 W(H′,M)：僅 t 不在 W 時，該捨牌提交後解除。此計算不得引用「已被過水禁止」的合法胡結果。改聽、摸花、暗槓不自行解除；加槓未被搶且正式成立才解除。明槓禁自摸不產生可胡選項，因此不另外建立過水。花胡不受過水；正常牌型加台仍受限制。

**R12 尾局。** 回應當下 A≤3 不准吃、碰、明槓；A>0 可暗／加槓。A0 取到一般牌仍可一般胡，否則捨牌、完成胡牌回應後流局；花無法補則依 R13 先檢查立即七搶一，未成立即流局，不捨不存在的牌。補槓取到尾花同理。海底台只給最後可用牌的自摸；最後捨牌胡不另加河底台。四風連打不另流局。

## 花胡事件與付款

**R13 花胡規則變更。** 花胡觸發改採[口袋麻將七搶一分支](https://pocket.funclub.com.tw/rule)，取代規劃階段依麻將之星推定的一律 E17；台數仍採本案 S24/S25。花不轉移，以七張／一張的實際持有者判定，沒有額外摸牌或補牌權轉移。花胡強制；單純花胡不用五面子。一般手牌若同時合法胡才計正常台項，且只結算一次。

**R14 花胡矩陣。** 下表「正常台」指依 R15 計算並排除花牌類 S06/S11 的結果，不含莊連台。純花胡不再加自摸、門清等正常台（本案補充）。

| 觸發 | 判定時點與牌數 | 付款及正常胡 |
|---|---|---|
| 某家已有 6 花，摸補取得第 7；另家已有 1 花 | 七花者正常補完至 E17 | 一花者付 8＋正常台；即使補牌正常自摸仍只一花者付 |
| 七花已在一家；原 0 花者摸補取得最後 1 花 | 公開花後立即終止，不等其補牌；七花者可 E16 | 一花者付 8；不計七花者正常牌型 |
| 一家取得第 8 花 | 本人的正常補花完成至 E17 | 其餘三家各付 8＋正常台 |
| 自己第 7／8 花但無牌完成補花 | 不成立需補完的花胡 | 流局；與上一行「別家摸最後一花立即七搶一」區分 |
| 明槓補花導致上述任一分布 | 花胡按對應分支成立 | 花胡不受明槓禁一般自摸；不計正常台，本案採花胡獨立例外 |
| 過水中取得花胡 | 同各分支 | 只計花胡，禁止正常牌型加台 |
| 全部起手補花完成時已為 7/1 或 8/0 | 立即強制花胡；閒家可 E16，不另補至 17 | 7/1 一花者付、8/0 三家付；莊家 E17 若同時一般胡可加正常台 |

最後一行為本案補充：開局花胡優先於其他人的天胡，不等待花胡持有人輪到摸牌。八花全部公開後不再有花補花。每筆付款另加 R16 的莊連台。

## 計台

**R15 計台算法。** 枚舉所有合法完整拆法及胡牌歸屬，每種獨立計台並套互斥，取最高；不混用不同拆法。平手依台項 ID、拆法序固定決定顯示。捨牌／搶槓補成的刻不算暗刻，其餘暗手刻及暗槓才算。W 為胡牌前暗手（自摸移除該張、放槍尚未加入）與既有面子之所有結構聽口，不因牌已出盡縮減。完整選值如下；台數分組參照[麻將之星](https://mahjongstar.waningames.com/Games/Game_Rule)。

第一巡自莊家首次捨牌開始，到三名閒家各完成第一次正常摸打、莊再摸以前；任一吃碰槓使人／地胡失效。補花不算第二次摸牌；加槓提出即使第一巡失效。本案不啟用宣告聽牌、天聽、地聽、半求人、河底撈魚；未列出台項不計。上表未排除且條件同時成立者可累計。

**R16 收付。** 四家 0 分起；底30、每台10，允許負分、零台胡、無封頂。一般胡由出牌／加槓者一人付，自摸三家各付，花胡依矩陣。每筆＝30＋10×(正常或花胡台＋S31＋S32)，不可將莊連台加到無關閒家。流局零收付。結算序號只提交一次，四家增減合計零。

**R17 莊圈。** 初始東圈、連莊 N0、移莊數0。莊胡或流局留莊，N+1；閒家胡則莊位下一家、N0、移莊數+1。每四次移莊進下一圈；第16次移莊完成一將，北圈末莊胡／流局仍續局。無連莊上限。先按本局 N 結算，再更新下局 N。

**R18 等待與資訊。** 自家操作、捨牌回應、搶槓回應、結算展示是可持續等待點；任何真人待答不得由動畫或 AI 逕自跳過。AI 僅可讀自己的暗手及公開資訊，不能讀他家暗槓牌種、牌牆順序或洗牌種子。每個等待點都必須有合法繼續路徑或已確定的結束結果。

## 來源與選定差異

行牌以[麻將之星](https://mahjongstar.waningames.com/Games/Game_Rule)為主要參照；花胡分支改採[口袋麻將](https://pocket.funclub.com.tw/rule)，不採該站天胡24、人胡8、花槓1等台數。起手補花參照[神來也補花](https://www.gamesofa.com/mj/?op=rule_guide&t=2d&topic=j)；莊圈參照[神來也連莊](https://www.gamesofa.com/mj/?op=rule_guide&t=2i&topic=j)，本案取消其連莊上限。固定留16、不隨槓增留、禁宣告聽、開局花胡優先與花胡交互作用均以上文明示選值為準；不宣稱完全複製任一平台。
