## 已處理的重要決策

1. **花胡不再一律要求17張。** 原規劃主要參照麻將之星，但其公開文字對「七搶一須補足」與「被七搶一立即胡」交界不夠清楚。本案改採[口袋麻將明文的七搶一分支](https://pocket.funclub.com.tw/rule)：自己取得第七花需補完；別家取得最後一花即成立，贏家可等效16張。不新增補牌權轉移。完整付款、起手與特殊情境見R13/R14。
2. **台數仍使用本案選定表。** 沒有一起改成口袋麻將的所有台數；例如本案花槓2、天／地／人胡16。起手花胡優先、明槓補牌鏈與平胡兩面限制等補充已明示，不能稱為全台唯一標準。
3. **過水使用結構判斷。** 以捨後暗手重加候選捨牌判斷是否可成胡，不用「因過水而不准胡」反過來解除過水；多面聽、暗槓、加槓分開規定。
4. **開局與搶槓牌權已修正。** 莊家補完E17直接選擇／首打；待搶槓第四張仍在原暗手且鎖定，pending只引用，避免多摸或重複牌。
5. **電腦與真人共用合法操作。** 電腦看不到他家暗手、暗槓牌種、牌牆順序；花胡由引擎強制處理，不給玩家任意放棄。
