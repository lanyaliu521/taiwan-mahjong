# M5.1共用牌效分析驗收

2026-10-05。M5.1完成；下一階段M5.2尚未啟動。凍結桌規TW16-CLASSIC-v1與對戰存檔schemaVersion=1保持相容。

## 實作與數學契約

src/analysis.ts共用於正式AI與後續練習／教練；hand.prepareHand共用驗證及副露容量，engine.discardBan共用吃牌禁捨。沒有新增依賴、改計台、增加練習或提示介面。

距離S＝到容量合法的五面子一對目標所缺張數減1。各花色用動態規劃枚舉目標順子／刻子／將牌，合併到5面子與1對；副露實體牌扣除容量，槓扣4。E16聽牌為0，E17完成為-1；E17選牌須先逐個合法捨牌回到E16。有效牌是加入後距離下降的牌種，結構有效但池中0張仍保留。

exactPool取剩餘一般牌的唯一實體ID；publicPool只取單一座位觀察，以ID去重扣已知牌，包含亮出的加槓牌、不猜他家暗槓。P=K/N；空池為null，K=0且N>0為0。公開未知牌含他家暗手與保留牌尾，比例不是實際可摸牌牆機率。分析拒絕非法手牌、第五張、牌池重複ID、無效計數與自家牌重疊。

示例提供一個最近合法目標的不重疊分配，非唯一拆法，也不保證顯示最多搭子。吃碰只分析引擎合法候選，叫牌後依法捨牌再比較；同指標最佳候選並列。牌型完成與當前合法WIN分開。

## 驗證結果

- npm test：200／200通過，約5.44秒；其中analysis.test.mjs新增15項。
- npm run build：通過；正式JS 66.83 kB，gzip 24.54 kB。
- 正式AI100次選牌：約12.70ms／次（全套同時執行），合計1,270.3ms，低於原5,000ms界線。
- node scripts/verify-m3.mjs M5.1-SIMULATION.json：3完整將、74局、9,121步、912次真人席決策、317次存檔還原，全部完成；57放槍、16自摸、1流局。每將16次莊位推進、付款零和及結算還原均通過；最慢決策30.10ms，約34.67秒。詳見[M5.1-SIMULATION](M5.1-SIMULATION.json)。

人工案例覆蓋台灣五面子一對、正常兩面聽口、副露刻子＋第四張單騎、非零容量陷阱、暗槓容量、四張字牌拆法、不同捨牌及並列候選、手算3／4機率、空池、有效牌耗盡、河牌／副露去重、待搶加槓亮牌、134遇2兩種吃法與禁捨、過水不可胡、輸入驗證。

另有80個四副露手牌，以獨立枚舉所有最後一組及將牌作距離／有效牌依據；60個閉手字牌案例對照42個五刻子加將合法目標。示例逐張核對未重複使用，完整目標與hand.isWinningHand交叉檢查，0向聽聽口與winningTiles交叉檢查。

資訊公平使用兩份不同他家暗手、暗槓牌種及牌牆順序、但真人觀察相同的合法GameState；分析與相同亂數下AI選擇均相同。既有規則、控制器、續局及正式AI回歸通過。
