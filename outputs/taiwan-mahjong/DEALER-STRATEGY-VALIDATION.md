# 對莊權重與阻止續莊：離線比較

2026-10-08。M6.1第三個離線子包；使用者強調「安全有權重，不讓莊家連莊很重要」。正式AI、教練與存檔均未接線。

## 目標與桌規

凍結RULES R17：莊胡或流局，莊家留莊且N+1；閒家胡才移莊。R16：連莊提高涉及莊家的收付，流局當局零收付。因此「避免現在放槍給莊」與「結束莊家連莊」是兩個目標。退守可能降低本次直接付款，卻讓流局續莊；自己盡快胡牌可以移莊，但進攻也有放槍風險。自己當莊時不套敵對莊家權重。

後續完整目標須同時考慮：自身點數期望、莊家續莊機會及未來成本、當局胡牌機會、牌效損失。莊家連莊數、公開進度與餘牌量將影響切換，不能直接把連莊數乘一個未校準係數就稱最佳策略。不得故意餵牌給其他AI形成合作，也不得放棄合法WIN來維持角色習慣。

## 已實作的最小實驗

`src/strategy-comparison.ts`只收引擎產生的自家Observation與三項明示偏好：允許比最佳合法捨牌多幾向聽、對莊／對其他家的未知安全證據權重。

先以合法候選的最低向聽加上容許損失建立門檻，再比較加權未知證據、向聽、公開有效進張K。每一家無充分安全證明加其權重，有證明加零；平手全部保留，無亂數或實體牌張數偏票。合法WIN優先；沒有捨牌則返回none，不虛構其他動作。權重限有限0–100，向聽損失整數0–5。

**未知不是危險、權重不是放槍率、分數不是期望損失。** 普通放槍的安全證明不涵蓋未來自摸、續莊率或整局損失。此刻只比較偏好；不提供校準威脅、不判斷對手已聽、不自動選擇攻守模式。最低向聽門檻也沒有約束同向聽的K損失；正式採用前須另評估這種代價，不能宣稱已保留全部速度。

## 可重現結果及消融

`npm run check`後執行`node scripts/research-risk.mjs`；完整輸出保存RISK-EXAMPLES.json。延用已驗證的五副露莊家構造局，自家三萬0向聽K5、只對莊有安全證明，一筒1向聽K12、對三家有證明。

| 實驗偏好 | 容許向聽損失 | 莊／閒權重 | 結果 |
|---|---:|---:|---|
| 純牌效 | 0 | 0／0 | 三萬，保留聽牌 |
| 全面退守 | 1 | 1／1 | 一筒，退出聽牌 |
| 阻莊候選偏好 | 0 | 3／1 | 三萬，保留聽牌且對莊安全 |
| 只放寬上列牌效門檻 | 1 | 3／1 | 一筒，仍選全桌安全 |

本例差異來自**牌效門檻**，不能聲稱只增加莊權重便改善選牌，更不能把「阻莊候選」名稱當成已證明減少續莊的效果。對莊權重3只是使一個未知莊家大於兩個未知閒家的偏好示範，沒有統計估計依據。測試另把相同公開牌情境的莊位改到2號：三萬的未知證據分由2變4；自己當莊時為2，不把自己當成敵人。
