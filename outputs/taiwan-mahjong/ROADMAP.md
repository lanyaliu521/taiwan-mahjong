# 決策訓練主線與完成條件

2026-10-09。依[產品方向決議](PRODUCT-DIRECTION.md)採L線；M0–M5.4完成史及M6研究保留於[舊ROADMAP](ROADMAP-HISTORY-20261008.md)。M6.1僅三個離線子包，不算整包完成，正式人格整合暫緩。

| 階段 | 交付與驗收 | 現況／排除 |
|---|---|---|
| L0 基準確認 | 對照本機、遠端、CI、正式資源，核對API與測試界線 | 本輪已完成查核；無新部署／瀏覽器互動驗收，不改功能 |
| L1-A 獨立證據驗收 | 牌效、安全、合法候選、資訊公平的獨立牌例與反例；通過AT-01～06適用部分 | 下一包；不實作人格、快照或UI |
| L1-B 證據格式與用語 | 最小證據封裝、版本、E1～E3範圍、未知與並列；補齊AT-01～06 | 待L1-A；不提供風險百分比或全局最優分數 |
| L2-A 決策快照 | 白名單、獨立版本鍵、大小限制、清除、失敗／衝突／還原；AT-07 | 待L1；不改既有Session／練習格式，不匯入全GameState |
| L2-B 局後檢討MVP | 少量靜態決策比較、原選擇及限制；AT-08～09及資料回歸 | 待L2-A；不做完整回放或未來分支 |
| L3-A 題庫 | 能力／題族分類、獨立審核、答案集合、理由與爭議標記 | 待L1，可與L2不同工作包推進；不靠AI選牌定正解 |
| L3-B 無提示測驗 | 訓練／保留測驗隔離、匹配難度、分項回饋；LT-01～03 | 待L3-A；不做排行榜、貨幣、雲端 |
| L4 玩家驗證 | 理解度、陌生題改善訊號、對局遷移；LT-04～05 | 待可試用MVP；不以少數人試用宣稱普遍有效 |
| L5 條件式攻守再立案 | 由L4證據定義必要模型、成本與獨立驗收 | 不自動開工，原M6研究不是上線授權 |

AT／LT定義見[調整報告第11節](TAIWAN-MAHJONG-PRODUCT-REALIGNMENT-REPORT.md)；執行方案見[L0-L1-PLAN](L0-L1-PLAN.md)。正式發布每包另需AT-10及G4，不能只引用歷史CI。

MVP為決策後候選差異、局後少量檢討、陌生題無提示評量。提示模式規劃為不提示／決策後解釋／即時輔助，尚未實作；評量以不提示為準。既有新手教學與娛樂回饋維護不擴張，阻斷或誤導問題仍優先修復。

桌面優先、窄畫面可用；具名支援的瀏覽器與手機待實機驗收。60題與6–10人試用是規劃建議，L3／L4才定實際規模。無帳號、後端、多桌規、多人與長期收益引擎。

每包先完成獨立驗證，再接UI／存檔，更新HANDOFF、受影響設計及驗收記錄。歷史文中的「下一包」均不能覆蓋本表。
