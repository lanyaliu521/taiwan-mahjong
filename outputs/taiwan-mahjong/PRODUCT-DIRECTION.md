# 產品方向變更決議

2026-10-09｜依使用者「根據調整報告改變專案方向」採納。[原始報告](TAIWAN-MAHJONG-PRODUCT-REALIGNMENT-REPORT.md)保留提案原文；本文件記錄此次採行範圍，不修改原作者的證據聲明。

## 已採行的定位

**台灣16張麻將進階玩家決策訓練工具。** 主要服務已能獨立行牌、理解基本向聽及有效進張，希望改善判斷理由的玩家。固定TW16-CLASSIC-v1，不宣稱所有台灣桌規通用最優。

以情境分析、決策檢討、無提示陌生題測驗為主線；完整單人對戰保留作連續決策與實戰遷移的驗證環境。優先順序：可信 → 可學 → 可量測 → 可實戰 → 娛樂與個性。

成功指標為「在已教學且可獨立評分的能力上，無提示陌生局面的判斷改善」。勝率、總點數、AI推薦一致率、測試數量均不能單獨證明學習成效；目前尚無學習成效驗證。

## 保留、調整與延後

- 保留：完整行牌、結算、續局、傳統牌面、純牌效練習、現行AI、合法引擎與分析器。
- 調整：教練呈現改以證據、候選取捨與限制為中心；純練習明確定位局部牌效，不稱防守訓練。尚未修改正式UI。
- 新主線：可信證據 → 少量局後決策檢討 → 審核情境題庫／無提示測驗 → 真人學習驗證。
- 維護不擴充：新手教學、事件鼓勵、既有美術；阻斷操作或誤導仍須修復。
- 延後：人格參數UI、自動攻守、完整回放／分支、長期收益模型、跨裝置履歷。
- 本輪不做：真人連線、帳號、課金、雲端、跨桌規、成就貨幣與排行榜。

「阻止莊家連莊」保留為局況取捨題材。流局同樣續莊；不能把安全捨牌等同阻莊成功，也不能把研究權重包裝為客觀概率或唯一正解。

## MVP與品質關卡

MVP讓玩家完成三件事：決策後看2–3個合法選項的可信差異；局後回顧少量代表性決策；在陌生題無提示作答並取得分項回饋。所有合法候選仍保留於證據資料；UI摘要不能假裝只有2–3個合法動作。

| 關卡 | 通過要求 | 現況 |
|---|---|---|
| G0 定位／範圍 | 主體玩家、MVP、延後範圍及衡量方式明確 | 本次已採行 |
| L0 基準 | 版本、現有能力與驗證邊界無歧義 | 查證見L0-L1-PLAN；本輪無新發布 |
| G1 證據 | 獨立牌例、E1–E3條件及文案，不以AI選擇自證 | 待L1 |
| G2 資料 | 快照公平、舊存檔相容、容量／衝突／失敗回退 | 待L2 |
| G3 可用與學習 | 題庫審核、操作／理解、陌生題評量 | 待L3–L4 |
| G4 發布 | 指定提交、CI、資源與受影響流程可追溯 | 每次正式交付重新驗證 |

新開發順序見[ROADMAP](ROADMAP.md)。本輪完成方向文件、L0查核與L1方案；下一個最小包為L1-A證據獨立驗收，不直接實作完整訓練系統。L5依學習證據另行立案，不因原M6研究存在就自動重啟。
