### 1. 硬安全充分條件的局部枚舉

枚舉萬／筒／索任一同門數牌1–9；候選t已在自己手中，U[t]取0–3，與t可組順子的其他種U取0–4。對每組容量，獨立檢查「t能否與未知牌形成將／刻／順」，再比對公開容量安全公式。共**13,700組數牌局部容量、401組判安全**，一致無反例；另驗7字牌×4未知同種量，共28組。字牌U=0安全，U≥1仍有成將可能。

這個枚舉只驗證局部組成的排除邏輯，沒有構造完整五面子一對、他家宣告面子或公共牌數總和，不能從未排除路徑推出完整對手一定可胡。全部三門同構，花牌不在普通胡形枚舉中。

以下可單獨重現數牌計數（Python標準庫）：

```python
from itertools import product
checked = safe_count = 0
for t in range(1, 10):
    kinds = list(range(max(1, t-2), min(9, t+2)+1))
    routes = [tuple(r for r in range(a, a+3) if r != t)
              for a in range(max(1, t-2), min(t, 7)+1)]
    limits = [range(4) if r == t else range(5) for r in kinds]
    for values in product(*limits):
        u = dict(zip(kinds, values))
        proof = u[t] == 0 and all(any(u[r] == 0 for r in p) for p in routes)
        can_group = u[t] >= 1 or any(all(u[r] >= 1 for r in p) for p in routes)
        assert proof == (not can_group)
        checked += 1
        safe_count += proof
assert (checked, safe_count) == (13700, 401)
```

成刻需另外兩張t，已包含在「U[t]≥1可成將」的存在性判斷中；不是把一張當兩張。對應引擎回歸未來仍要驗實體去重、暗槓遮罩、數牌邊界及特殊花胡範圍。

### 2. 候選最大最小縮放會改變原本選擇

合成特徵A=(速度0.9、風險0.8)，B=(0.7、0.4)，D=(0、1)。D在兩軸均被B支配。偏好分為0.6×速度−0.4×風險：

| 轉換方式 | 只有A、B | 加入D | 含意 |
|---|---|---|---|
| 每批候選各軸min–max | A | B | 無關劣勢候選改變兩軸相對尺度 |
| 使用原先固定0–1尺度 | B | B | 三候選6種列舉順序均保持B |

固定尺度的A=0.22、B=0.26、D=−0.4。候選min–max下原先A=0.2、B=0；加入D後A≈0.3333、B≈0.4667。這是選擇穩定性反例，不是麻將風險模型；規格因此要求固定轉換並另測劣勢候選不影響選擇。

## 風格可辨識性與單軸消融

先建立固定Observation情境集，三模板同能力、同計算預算；不要求每題都選不同牌。情境至少包括：等向聽快／穩、叫牌有益但失門清、無效叫牌、價值可信／耗盡、弱起手早段資訊不足、弱手遇公開威脅、改善回攻、三種槓。某題只有一個合理動作時，全模板相同是正確結果。

一次只調一個參數，按0、.25、.5、.75、1掃描；其他特徵與亂數固定。記錄改變的原因、界線及是否出现反向行為。若兩軸在全部機會中造成相同變化，合併或移除，不用「人格比較複雜」掩飾重複。價值特徵不可靠時，對應模板不能進首版。

叫牌率須以**有實質收益且合法的叫牌機會**為分母；退守率以存在風險／速度衝突的決策為分母。原始全局副露率也可報，但不能把沒遇到叫牌機會說成風格不積極。每次變化要檢查是否來自能力差異、固定槓加分或抽籤票數，而非個性。

## 對局比較：以配對與座位輪換減少誤判

建議先小批次驗流程，再擴大；數量是執行建議，非足以證明優劣的固定樣本。

1. **煙霧批次**：48個未用於起手調校的種子×4個座位輪換，單局配對。候選與基線從相同發牌狀態起跑，離線以固定基線代替真人，核對終止、牌權與付款；不用單局結果宣稱每將更強。
2. **完整將試驗**：先32組種子×4輪換，維持莊連／圈風正常演進，記錄完成率與配對每將淨分；不足再按預先規則追加。每將沒有固定局數上限，研究若因時間預算截斷，須報未完成與原因，不改桌規強制結束、不只留下短將。
3. **校準／保留集**：開發情境與調參對局為校準集；最終驗證使用事先固定、未調參的另一批種子及混合對手。不要每次看保留集再改權重。先凍結可接受強度代價、樣本追加／停止規則，再看最終結果。

每次記錄rulesVersion、policyVersion、模板解析值、初始AI亂數、種子清單、席位／莊位與執行環境。評估調度器可以知道測試種子，正式策略不能接種子或牆。候選策略改變叫牌／槓後，未來取牌次序自然分歧；不能為「公平配對」強迫兩條路摸到相同後續牌。

席位輪換既要控制誰拿哪副起手，也要控制莊位／門風；結果按座位及模板分層。候選先對固定基線及固定混合對手，再看人性化三家同桌；只自我對戰無法知道相對既有AI的強度。真人試玩感受另評，不能從四AI離線對局推真人勝率。

最小輪換方法：每個seed只建立一次合法「起手補花完成、尚未首打」的完整快照（含既定首莊），對照／候選各複製同一份；四次輪換只改**策略配置落在哪個座位**，不旋轉牌牆或改首莊。這樣同一配對初始牌完全一致，目標策略輪流拿四席起手與門風。以初始完整快照摘要雜湊、每席起手／花牌數及莊位核對，摘要供離線評估而不傳給策略。直接花胡終止的seed另記為策略無作用的事件，不能悄悄替換成好打的seed。

完整將試驗從同一已補花快照及同一AI亂數起跑，之後按各自合法結果自然進行，將長、連莊及後續手牌可分歧。固定種子只保證初始條件配對，不保證後續每局或每席相同。若研究要重設初莊來平衡，另作預先指定的分層因子，不能在其中一邊臨時改莊。

| 指標 | 報告方式 | 常見誤判 |
|---|---|---|
| 規則／保存／公平錯誤 | 次數與反例，要求0 | 平均分較高就忽略一次非法動作 |
| 每局／每將淨分 | 配對差、分布、完整將數，並報信賴區間 | 只看勝率，或把未完成將當零分 |
| 胡與損失 | 普通放槍、搶槓、自摸、花胡、各類付款與得分分開 | 少放槍就認定更強，忽略長期不胡與自摸損失 |
| 風格行為 | 按機會分母的副露／退守／路線保留／轉向 | 用不同起手機會造成的差異冒充個性 |
| 計算成本 | 每決策P50／P95／P99及最差，分吃碰／槓／普通捨牌 | 只看平均或桌面Node速度就宣稱手機通過 |

同一種子輪換席位、同將多局及三家起手均相關，統計按完整種子／將的群組配對或bootstrap，不能把每巡當獨立樣本。先檢查均值與區間是否支持設計目的；「沒有顯著差異」不等於已證明等強。勝率及放槍率的分母、花胡處理、截斷與失敗案例須一起報告。

| 名稱 | 分子 | 分母／單位 |
|---|---|---|
| 普通放槍暴露率 | 該策略捨牌造成普通ron付款的次數 | 該策略已接受的DISCARD次數；不含加槓 |

| 每局放槍率 | 該策略普通ron或robKong付款的局數 | 該策略參與的已完成局數，含流局與花胡；兩來源再分報 |
| 胡牌率 | 該策略成為贏家的局數 | 同一已完成局數；普通ron／自摸／搶槓／花胡分報 |
| 自摸／花胡損失 | 因各事件的付款次數及總分 | 每已完成局與每完整將各報，非普通放槍 |

強制花胡是結果，不是WIN動作次數。加槓提案被接受但未成立仍進搶槓暴露率分母；不主動槓的試驗不得把0/0寫成0%表現更好。未完成將中的已完成局可進單局統計，但不冒充完整將，另列截斷層；引擎錯誤／保存失敗不是普通流局。

## 玩家盲測與介面

先做8–12人小規模探索，包含熟悉台灣16張者與新手；這是找問題，不是代表性人性化研究。只展示正常可見牌桌／公開動作，隱藏牌風標籤、統一外觀與節奏，讓玩家在有取捨的多局後選三種牌風並說原因。三選一隨機基準為1/3；報混淆表、信心及可引用的可見行為，不只報正確率。相同受試者多題不是獨立玩家樣本。

另外以正式標籤試玩，確認提示是否幫助辨識而沒有洩漏暗手。辨識度、可預測但不死板、規則信任、挫折與操作流暢分開問。不能靠名稱、頭像或較慢出手獲得的辨識率宣稱決策本身像人。不在本次設計階段邀請或聯絡他人。

探索階段可先用每風格至少4個有取捨機會的短片段作入選條件，數字是試驗起點而非充分樣本；三風格曝光量與情境類別盡量相等。受試者以六種風格排列輪換呈現次序，片段順序另平衡，不先連看某風格多個相似例子；每人不重複看同題不同標籤。報每位玩家的混淆與有效機會數，再彙總，避免把片段難易或熟悉順序誤當個性辨認。
